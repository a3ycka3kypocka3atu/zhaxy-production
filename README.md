# ZHAXY Production

Static one-page demo. Requires Node.js 18+ for the dependency-free build and Python 3 for the local server.

- `npm run dev`: serve source on http://localhost:4173
- `npm run check`: JavaScript syntax checks
- `npm run build`: generate `dist/`

Edit content in `src/index.html` and visual styles in `src/styles.css`. Vercel uses the static output configured in `vercel.json`. Current implementation and verification are recorded only in PROJECT_STATE.md.
